# CrediSense AI

## Intelligent Credit Risk & Loan Assessment System

CrediSense AI is a machine learning based FinTech prototype that analyzes applicant financial information and predicts the probability of loan approval.

## Features

- Credit risk prediction
- Loan approval prediction
- Approval probability
- Risk classification
- Financial factor analysis
- Interactive Streamlit dashboard
- Random Forest classification model
- Model performance evaluation

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Streamlit
- Joblib

## Machine Learning Workflow

1. Generate financial applicant data
2. Perform data preparation
3. Split data into training and testing sets
4. Train Random Forest classifier
5. Evaluate model
6. Save trained model
7. Integrate model with Streamlit
8. Generate real-time predictions

## Input Features

- Age
- Annual Income
- Credit Score
- Loan Amount
- Loan Term
- Existing Debt
- Employment Type
- Previous Defaults
- Dependents

## Output

The system provides:

- Approval probability
- Risk level
- Loan recommendation
- Key financial risk factors

## Disclaimer

This project is an educational prototype using synthetic data and should not be used for real-world lending decisions.
